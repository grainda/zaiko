# 在庫管理アプリ

このアプリは、主に家の在庫管理を行うための React Native 製アプリです。

## 主な機能

- 商品の一覧表示
- 在庫数によるフィルタリング
- 商品情報の管理（名前、場所、アイコン、在庫数）

## セットアップ方法

1. リポジトリをクローン
2. 必要なパッケージをインストール
   ```
   npm install
   ```
3. アプリを起動
   ```
   npm start
   ```

## フォルダ構成

- `/screens` ... 画面コンポーネント
- `/itemManager` ... 商品データ管理

## 使用技術

- React Native
- TypeScript
