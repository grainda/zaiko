# 在庫管理アプリ

このアプリは、主に家の在庫管理を行うための React Native 製アプリです。

## 主な機能

- **ホーム画面**：スワイプジェスチャー（またはタブ）で 2 つの画面を簡単に切り替え可能。
- 左側画面（在庫管理）: 在庫一覧の閲覧・編集を管理。リアルタイムで在庫数を更新
- 右側画面（買い物メモ確認）: 在庫が少ない商品を自動的にリストアップ。リストに追加していない商　品でも買い足す必要がある場合はこの画面にメモをすることも可能。

## セットアップ方法

1. リポジトリをクローン
2. 必要なパッケージをインストール
   ```
   npm install
   ```
3. アプリを起動
   ```
   npm start
   ```

## 開発背景と今後の予定

- 開発背景
  個人開発のアイデアを探していたところ、母から家庭の在庫（洗剤やトイレットペーパーなど、無くなったら困るもの）の残数を管理するアプリと買い物メモアプリの要望を受けました。私自身も、買い物から帰宅後に買い忘れに気づくことが多かったため、在庫管理と買い物メモの二つの機能を統合したこのアプリの開発を決意しました。このアプリを通じて、日常の買い物フローをよりスムーズにし、ユーザーが買い物をする時の煩わしさから解放されることを目指しています。

- 今後の予定
  - 基本機能の実装  
    在庫管理機能は実装済みですが、買い物メモ機能は未完成のため、今後はこの部分の開発を最優先で進めます。
  - 通知機能の追加  
    在庫が少なくなった商品や買い物メモに新しい書き込みがあった場合、アプリから通知を送信し、買い物のタイミングをお知らせします。
